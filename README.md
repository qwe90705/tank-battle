# 坦克大战 · Tank Battle

经典「坦克大战（Battle City）」风格的网页闯关游戏。纯 HTML + Canvas + JavaScript 实现，无任何外部依赖，双击 `index.html` 即可游玩。

## 玩法

- 消灭不断从战场顶部出击的敌方坦克，保护画面下方的**基地（老鹰）**。
- 敌人会进攻基地，也会追击你；基地被摧毁即游戏结束。
- 共有 **6 关**，越往后敌方越强、墙体越硬。

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑ ↓ ← →` 或 `W A S D` | 移动 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 进入下一关 |
| `M` | 静音开关 |

## 道具

击毁敌方坦克时有几率掉落道具：

- **★ 火力**：提升火力（二级双发，满级炮弹可击穿钢墙）
- **＋ 生命**：额外一条命
- **护盾**：短暂无敌
- **✸ 炸弹**：清空场上所有敌人
- **◷ 冻结**：冻结敌人数秒

## 敌人类型

| 类型 | 说明 |
| --- | --- |
| 普通 | 基础敌人，速度一般 |
| 快速 | 移动快、射速高 |
| 装甲 | 需两发子弹才能击毁 |
| 重甲 | 需三发，子弹可击穿钢墙 |

## 本地运行

直接用浏览器打开 `index.html` 即可。若需本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术说明

- 战场 26×26 格（每格 16px），左右对称生成，中央走廊保证可通行。
- 关卡地图由代码按种子生成，每关结果稳定。
- 音效使用 WebAudio 实时合成，无音频资源文件。
- 最高分保存在浏览器 `localStorage`。

## 项目结构

```
tank-battle/
├── index.html       # 页面入口
├── css/style.css    # 样式
└── js/
    ├── levels.js    # 关卡生成 / 敌人编制
    ├── entities.js  # 坦克 / 子弹 / 道具数据与数值
    ├── sprites.js   # 像素绘制（坦克 / 地形 / 老鹰 / 图标）
    ├── audio.js     # WebAudio 音效
    └── game.js      # 主逻辑（状态机 / 碰撞 / AI / 渲染）
```
